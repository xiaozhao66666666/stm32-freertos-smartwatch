# 第六章：逐步复刻指南

## 6.1 复刻路线图

```
第1步: 裸机点灯 (30分钟)
第2步: OLED点亮 (1小时)
第3步: FreeRTOS多任务闪烁 (1小时)
第4步: 按键中断+队列 (2小时)
第5步: 菜单系统 (3小时)
第6步: 应用开发 (每个1-2小时)
```

## 6.2 详细步骤

### 第1步：裸机点灯
```
1. CubeMX新建工程，选择STM32F103C8
2. 配置PC13为GPIO_Output
3. 生成Keil工程
4. main.c中while(1)里：
   HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
   HAL_Delay(500);
5. 编译→下载→LED闪烁 ✓
```

### 第2步：OLED点亮
```
1. CubeMX使能I2C1 (PB6-SCL, PB7-SDA)
2. 添加u8g2库到工程
3. main.c中初始化u8g2，显示"Hello"
4. 编译→下载→OLED显示文字 ✓
```

### 第3步：FreeRTOS多任务
```
1. CubeMX使能FreeRTOS (CMSIS_V2)
2. 创建2个任务：LED闪烁 + OLED刷新
3. 各任务独立运行，互不阻塞
4. 验证多任务并发 ✓
```

### 第4步：按键中断+队列
```
1. CubeMX配置4个GPIO为EXTI (下降沿)
2. NVIC使能对应中断
3. freertos.c中实现HAL_GPIO_EXTI_Callback
4. 创建队列 → ISR发送 → 任务接收
5. 按键→OLED显示键值 ✓
```

### 第5步：菜单系统
```
1. 从mytasks/ShowMenu.c复制代码
2. 添加Data.c中的图标位图
3. 实现左右键导航+确定键选择
4. 实现任务挂起/恢复切换应用
5. 菜单完整可用 ✓
```

### 第6步：应用开发
```
逐个添加应用任务：
1. ShowCalendar.c - 日历
2. ShowFlashLight.c - 手电筒(OLED全白)
3. ShowDHT11.c - 温湿度(需DHT11驱动)
4. ShowClock.c - 秒表
5. ShowSetting.c - 设置
```

## 6.4 调试技巧

### HardFault排查
```
1. 查看SCB寄存器: CFSR (Configurable Fault Status Register)
2. 常见原因:
   - 栈溢出: 增大任务栈大小
   - 访问空指针: 检查队列/信号量是否创建成功
   - 未对齐访问: 检查结构体定义
3. 在HardFault_Handler中打断点，看LR寄存器判断是MSP还是PSP
```

### 栈使用量监控
```c
// 在任务中调用
UBaseType_t highWaterMark = uxTaskGetStackHighWaterMark(NULL);
printf("栈剩余: %d words\n", highWaterMark);
// 如果剩余<10个字，有栈溢出风险！
```

### 任务状态查看
```c
// 用vTaskList()获取所有任务状态
char taskList[512];
vTaskList(taskList);
printf("%s", taskList);
// 输出示例:
// ShowMenuTask    R   1   256   ...
// ShowDHT11Task   B   1   128   ...
// ShowClockTask   S   1   128   ...
// R=Running, B=Blocked, S=Suspended, D=Deleted
```
