# 第四章：u8g2图形库与菜单系统

## 4.1 为什么选择u8g2？

| 对比 | u8g2 | Adafruit GFX | 自己写驱动 |
|------|------|-------------|-----------|
| 支持屏幕 | 100+种 | 有限 | 1种 |
| 中文字体 | ✅ 内置 | ❌ 需额外处理 | ❌ |
| 位图 | ✅ XBMP | ✅ | ✅ |
| Flash占用 | ~20KB | ~5KB | ~2KB |
| 学习曲线 | 中 | 低 | 高 |

本项目选择u8g2的核心原因：**内置中文字体+页缓冲模式省内存**。

## 4.2 页缓冲模式 (Page Buffer)

```c
// u8g2初始化
u8g2_t u8g2;
u8g2_Setup_ssd1306_i2c_128x64_noname_f(
    &u8g2,                    // 句柄
    U8G2_R0,                  // 不旋转
    u8x8_byte_hw_i2c,        // 使用STM32硬件I2C
    u8g2_stm32_delay          // 延时函数
);
u8g2_InitDisplay(&u8g2);
u8g2_SetPowerSave(&u8g2, 0); // 唤醒显示
```

### 页缓冲绘制流程
```c
// 每次绘制一个完整帧：
u8g2_ClearBuffer(&u8g2);     // 1. 清空内部128字节页缓冲

// 2. 所有绘制操作（可调用任意多次）
u8g2_SetFont(&u8g2, u8g2_font_wqy16_t_chinese1);
u8g2_DrawUTF8(&u8g2, 10, 20, "你好世界");
u8g2_DrawXBMP(&u8g2, x, y, w, h, bitmap_data);
u8g2_DrawCircle(&u8g2, x, y, r, U8G2_DRAW_ALL);

u8g2_SendBuffer(&u8g2);      // 3. 发送当前页到OLED → 换下一页
                               //    重复直到8页全部发送完毕
```

### 为什么省内存？
- 全帧缓冲模式：128×64=1024字节（对20KB SRAM的F103是巨大开销）
- 页缓冲模式：128字节/页 × 8页 = 仅128字节常驻SRAM
- 代价：需要反复发送（不影响显示效果，I2C足够快）

## 4.3 菜单UI架构

```
┌──────────────────────────────┐
│ ←   [图标]    →              │  ← 左右箭头+应用名
│                              │
│  [日历] [🔦]  [💧] [⏰] [⚙]  │  ← 5个应用图标
│       ●  ○  ○  ○  ○        │  ← 选中指示圆点
│  ┌──────────────────────┐   │
│  │    选中框(32×32)      │   │  ← 选中框动画
│  └──────────────────────┘   │
└──────────────────────────────┘
```

### 菜单状态机
```c
// 左右键 → 移动选中框
if (key_data.rdata == 1) {
    dock_pos != 0 → dock_pos--;  // 左移
    for each icon: ui_right(&icon.x, 2);  // 所有图标右移
}
if (key_data.ldata == 1) {
    dock_pos < 4 → dock_pos++;   // 右移
    for each icon: ui_left(&icon.x, 2);
}

// 确定键 → 启动对应应用
if (key_data.exdata == 1) {
    switch(dock_pos) {
        case 0: vTaskResume(xShowCalendarTaskHandle);  break;
        case 1: vTaskResume(xShowFlashLightTaskHandle); break;
        case 2: vTaskResume(xShowDHT11TaskHandle);     break;
        case 3: vTaskResume(xShowClockTaskHandle);     break;
        case 4: vTaskResume(xShowSettingTaskHandle);   break;
    }
    vTaskSuspend(NULL);  // 菜单自己挂起
}
```

## 4.4 位图数据存储

所有图标位图声明为`const`，由编译器自动放入Flash：

```c
// Data.c 中定义
const uint8_t cleder_data[128] = {  // 日历图标, 32×32像素
    0xFF, 0xFF, 0xFF, ...
};
ui cleder = {"cleder", 0, cleder_data, 0, 0, 32, 32};

// 在Flash中，不占SRAM！
```

位图格式：XBMP (X Bitmap)，每字节8个水平像素，MSB=最左。
