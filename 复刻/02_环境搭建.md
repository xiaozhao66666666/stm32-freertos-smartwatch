# 第二章：环境搭建 — STM32CubeMX + Keil MDK

## 2.1 所需软件

| 软件 | 用途 | 下载 |
|------|------|------|
| STM32CubeMX | 引脚配置 + HAL代码生成 | ST官网 |
| Keil MDK-ARM 5 | 编译调试 | ARM官网 |
| J-Link/ST-Link驱动 | 下载调试器驱动 | SEGGER官网 |
| 串口助手 | 调试输出 | 任意 |

## 2.2 CubeMX配置步骤

### Step 1: 新建工程
```
1. 打开 STM32CubeMX
2. New Project → 搜索 STM32F103C8Tx
3. 选择 LQFP48 封装
```

### Step 2: 配置时钟
```
HSE: Crystal/Ceramic Resonator (8MHz外部晶振)
→ PLL: HSE × 9 = 72MHz
→ SYSCLK = 72MHz
→ APB1 = 36MHz, APB2 = 72MHz
```

### Step 3: 配置外设
```
I2C1: SDA=PB7, SCL=PB6 (连接OLED)
TIM1: Channel1 PWM (蜂鸣器)
GPIO: PC11/PC10/PB1/PB0 → EXTI中断 (4个按键)
GPIO: PC13 → Output (板载LED)
```

### Step 4: 配置FreeRTOS
```
Middleware → FREERTOS → Interface: CMSIS_V2
  - Tasks: 创建 defaultTask
  - Timers: 使能软件定时器
  - Heap: heap_4.c (最常用)
  - Total Heap Size: 3072 bytes
```

### Step 5: 生成代码
```
Project Manager → Toolchain: MDK-ARM
→ Generate Code
```

## 2.3 Keil工程设置

### 添加源文件
```
1. 打开 MDK-ARM/hal_freertos_u8g2.uvprojx
2. 右键工程 → Add Group:
   - u8g2/     (u8g2图形库)
   - mytasks/  (应用任务)
   - driver/   (DHT11等驱动)
3. 添加对应.c文件
```

### 包含路径
```
Options → C/C++ → Include Paths:
  ../Core/Inc
  ../Drivers/STM32F1xx_HAL_Driver/Inc
  ../Middlewares/Third_Party/FreeRTOS/...
  ../u8g2/csrc
  ../mytasks
  ../driver
```

### 下载配置
```
Options → Debug:
  Use: ST-Link Debugger
  Settings → Port: SW
  Flash Download → Erase Sectors → Program → Verify
```

## 2.4 烧录步骤
```
1. ST-Link连接开发板 (SWDIO + SWCLK + GND)
2. Keil → Build (F7) → 确认0错误
3. Load (F8) → 下载到Flash
4. 复位 → OLED显示菜单界面
```
