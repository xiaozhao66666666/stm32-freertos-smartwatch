# 第一章：RTOS智能手表 — 项目概述与架构

## 1.1 项目背景

本项目是STM32F103 + FreeRTOS的多任务智能手表系统。通过u8g2图形库驱动128×64 OLED屏幕，实现了带图标的多应用菜单系统，包含5个独立应用。

## 1.2 系统架构

```
┌──────────────────────────────────────────────────────────┐
│                   FreeRTOS 调度器                         │
│                                                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐               │
│  │ 按键中断  │  │ 定时器1  │  │ 定时器2  │  (底层)       │
│  │ (ISR)    │  │ (1秒)    │  │ (100ms)  │               │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘               │
│       │Queue         │Timer CB    │Timer CB              │
│       ▼              ▼            ▼                      │
│  ┌──────────────────────────────────────┐               │
│  │         ShowMenuTask (主菜单)         │  (UI层)       │
│  │   - 队列接收按键事件                  │               │
│  │   - 状态机处理菜单导航                │               │
│  │   - vTaskResume/Suspend 调度应用      │               │
│  └──────────────────────────────────────┘               │
│       │Resume                                            │
│       ├────→ ShowCalendarTask  (日历)                    │
│       ├────→ ShowClockTask     (秒表)                    │
│       ├────→ ShowDHT11Task     (温湿度)    (应用层)      │
│       ├────→ ShowFlashLightTask(手电筒)                  │
│       └────→ ShowSettingTask   (设置)                    │
│                                                          │
│  ┌──────────────────────────────────────┐               │
│  │  HAL 硬件抽象层                       │  (驱动层)     │
│  │  GPIO | I2C | TIM | NVIC | DMA      │               │
│  └──────────────────────────────────────┘               │
└──────────────────────────────────────────────────────────┘
```

## 1.3 任务列表

| 任务名 | 栈大小 | 功能 | 运行条件 |
|--------|--------|------|----------|
| defaultTask | 512B | 启动定时器 | 上电就运行 |
| ShowTimeTask | 512B | 状态栏显示 | 持续运行 |
| ShowMenuTask | 1KB | 主菜单+按键处理 | 持续运行(阻塞队列) |
| ShowCalendarTask | 1KB | 日历应用 | 用户选择后唤醒 |
| ShowClockTask | 512B | 秒表时钟 | 用户选择后唤醒 |
| ShowDHT11Task | 512B | 温湿度 | 用户选择后唤醒 |
| ShowFlashLightTask | 512B | 手电筒 | 用户选择后唤醒 |
| ShowSettingTask | 1KB | 设置菜单 | 用户选择后唤醒 |
| ShowWoodenFishTask | 512B | 木鱼游戏 | (已注释) |
| Timer Service | - | 执行定时器回调 | FreeRTOS内部 |

## 1.4 内存布局

```
STM32F103C8 SRAM: 20KB (0x20000000 ~ 0x20005000)

┌──────────────────────┐ 0x20005000
│    系统栈 (MSP)      │
├──────────────────────┤
│    堆 (Heap)         │ ← FreeRTOS动态内存 (任务栈/队列)
│    configTOTAL_HEAP  │
├──────────────────────┤
│    全局变量/静态变量  │
│    .data + .bss      │
├──────────────────────┤
│    u8g2 页缓冲 (128B)│
│    图标位图 (Flash)  │ ← const数据不占SRAM
└──────────────────────┘ 0x20000000
```

## 1.5 你将学到的技能

1. **FreeRTOS任务管理**：创建/挂起/恢复/删除
2. **消息队列**：ISR→任务通信
3. **软件定时器**：周期性任务
4. **u8g2图形库**：OLED页缓冲模式
5. **中断处理**：NVIC优先级配置
6. **HAL库使用**：CubeMX配置+代码生成
7. **实时系统调试**：HardFault排查、栈溢出检测
