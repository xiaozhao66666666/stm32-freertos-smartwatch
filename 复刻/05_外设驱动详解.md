# 第五章：外设驱动详解

## 5.1 DHT11 温湿度传感器

### One-Wire协议
```
主机发送起始信号:
  拉低 ≥18ms → 拉高20~40μs → 释放总线

DHT11响应:
  拉低80μs → 拉高80μs

数据传输 (40位 = 湿度整数+小数+温度整数+小数+校验):
  每位: 拉低50μs → 拉高
    高电平26~28μs = '0'
    高电平70μs = '1'
```

### 代码实现要点
```c
// DHT11读取函数（微秒级延时）
uint8_t DHT11_Read_Data(uint8_t *temp, uint8_t *humi) {
    // 1. 主机拉低18ms
    DHT11_OUT_LOW();
    delay_us(18000);
    DHT11_OUT_HIGH();
    delay_us(30);

    // 2. 等待DHT11响应
    if (!DHT11_IN()) return 1;  // 超时

    // 3. 读取40位数据
    for (int i = 0; i < 40; i++) {
        while (!DHT11_IN());  // 等低电平结束
        delay_us(40);          // 等40μs后采样
        if (DHT11_IN())        // 高=1
            buf[i/8] |= (1 << (7 - i%8));
    }

    // 4. 校验
    if (buf[4] != buf[0]+buf[1]+buf[2]+buf[3])
        return 2;  // 校验错
}
```

### DHT11任务设计
```c
void ShowDHT11Task(void *params) {
    while(1) {
        uint8_t temp, humi;
        if (DHT11_Read_Data(&temp, &humi) == 0) {
            u8g2_ClearBuffer(&u8g2);
            // 显示温度
            u8g2_DrawStr(&u8g2, 10, 30, "Temp:");
            u8g2_SetCursor(&u8g2, 70, 30);
            u8g2_Printf(&u8g2, "%d C", temp);
            // 显示湿度
            u8g2_DrawStr(&u8g2, 10, 50, "Humi:");
            u8g2_Printf(&u8g2, "%d %%", humi);
            u8g2_SendBuffer(&u8g2);
        }
        vTaskDelay(2000);  // DHT11采样间隔≥1秒
    }
}
```

## 5.2 无源蜂鸣器驱动

### PWM驱动原理
```c
// 无源蜂鸣器需要方波才能发声，用TIM1的PWM输出
// 频率 = 定时器时钟 / (PSC+1) / (ARR+1)

// 初始化
void buzzer_init(void) {
    HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);
}

// 发出指定频率和时长的声音
void buzzer_buzz(uint16_t freq, uint16_t duration_ms) {
    // 计算PSC和ARR使PWM频率=freq
    uint16_t arr = 1000000 / freq - 1;  // 1MHz / freq
    __HAL_TIM_SET_AUTORELOAD(&htim1, arr);
    __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, arr/2);  // 50%占空比
    vTaskDelay(duration_ms / portTICK_PERIOD_MS);
    __HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, 0);  // 关闭
}
```

### 本项目蜂鸣器使用场景
- 按键按下：`buzzer_buzz(2000, 100)` （2000Hz，100ms）
- 应用切换：`buzzer_buzz(2000, 100)`
- 错误提示：更低频更长时间

## 5.3 按键驱动（GPIO中断）

### CubeMX配置
```
PC11 → GPIO_EXTI11 (右键)
PC10 → GPIO_EXTI10 (左键)
PB1  → GPIO_EXTI1  (确定键)
PB0  → GPIO_EXTI0  (返回键)

触发方式: 下降沿 (Falling Edge)
上拉: 使能内部上拉 (Pull-up)
```

### 中断处理流程
```c
// stm32f1xx_it.c 中（CubeMX自动生成）
void EXTI0_IRQHandler(void) {
    HAL_GPIO_EXTI_IRQHandler(GPIO_PIN_0);
}

// freertos.c 中（用户编写）
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
    // 软件消抖
    for(int i = 0; i < 5000; i++) {}

    Key_data key_data = {0};

    if(GPIO_Pin == GPIO_PIN_11) key_data.rdata = 1;   // 右
    if(GPIO_Pin == GPIO_PIN_10) key_data.ldata = 1;   // 左
    if(GPIO_Pin == GPIO_PIN_1)  key_data.updata = 1;  // 确定
    if(GPIO_Pin == GPIO_PIN_0)  key_data.exdata = 1;  // 返回

    // 发送到菜单任务
    xQueueSendToBackFromISR(g_xQueueMenu, &key_data, NULL);

    // 板载LED闪烁指示
    HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET);
}
```
